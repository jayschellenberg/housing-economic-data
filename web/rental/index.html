About

What this is

Filter, map and chart the firm's weekly scrape of Manitoba rental listings. The site itself holds no data: you connect the shared RentalDashboard\export folder once, it is read into this browser, and after each weekly publish a Reload picks up the new files. Nothing is uploaded anywhere.

Medians follow the dashboard's policy: rents inside the display band only, suppressed below the minimum count. "Canonical" de-duplicates a unit listed on several sites.

Rental data Not connected

Connect the shared RentalDashboard folder (Dropbox → SharedInfo → Apps). Its export subfolder is read into this browser and refreshed after each weekly publish; its evidence subfolder lets you open archived listing pages. Nothing is uploaded.
